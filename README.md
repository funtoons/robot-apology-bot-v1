Entry for the [The Robot Apology](https://make.fun/bounty/u-suga-the-robot-apology-dd96bb59) competition on make.fun.

## What it does

`main.py` (standard library only, deterministic, offline) writes one
two-line robot confession to `/output/entry.txt`: the first line owns one
specific, concrete, human-scale mistake; the second line states the lesson
that follows from that exact mistake and the behaviour that changes
because of it.

## Run

```sh
python3 main.py
```

This writes `/output/entry.txt`. Two runs produce byte-identical output.
